# Check if an online animal medicine retailer is accredited

Source: https://www.gov.uk/check-animal-medicine-seller-accredited
Fetched: 2026-11-04
Publisher updated: 2015-10-02T15:26:57+01:00

Check if an online retailer that sells pet medicines is on the Veterinary Medicines Directorate’s accredited internet retailer scheme (AIRS)


Check if a retailer is part of the Accredited Internet Retailer Scheme (AIRS) .

 Accredited sellers must prescribe the most appropriate medicine for the animal and advise customers how to use the medicine safely.

 This is a voluntary scheme. Retailers do not have to be accredited to sell animal medicines.

 Contact the Veterinary Medicines Directorate ( VMD ) if you have a query about a listed retailer.
