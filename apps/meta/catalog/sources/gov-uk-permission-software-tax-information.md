# Manage permissions for tax software

Source: https://www.gov.uk/permission-software-tax-information
Fetched: 2026-11-04
Publisher updated: 2024-12-04T17:54:52+00:00

Manage, check and withdraw permission you've given to software applications to share and update your tax information

You may be using software to interact with HM Revenue and Customs ( HMRC ), for example to send your Self Assessment tax return.

 This service is also available in Welsh (Cymraeg) .

 You can use this service to:

 check which software you’ve given permission to

 remove permission from any software, for example permission to file your return

You’ll need to sign in to use this service. If you do not already have sign in details, you’ll be able to create them.

 You’ll be told when you sign in if you need to prove your identity. This is to keep your details safe and usually involves using photo ID like a passport or driving licence. 

 You’ll also need a permanent National Insurance number.
