# Apply to work on a tree that's protected

Source: https://www.gov.uk/apply-work-on-protected-tree
Fetched: 2026-11-04
Publisher updated: 2012-05-02T17:27:21+01:00

You may need to make a 'works to trees' application if they’re protected by a ‘tree preservation order’ (TPO) or you live in a conservation area.

You may need to make a ‘works to trees’ application if they’re protected by a ‘tree preservation order’ (TPO) or you live in a conservation area. Work can include trimming, topping, uprooting or lopping branches.

Available in England and Wales only
