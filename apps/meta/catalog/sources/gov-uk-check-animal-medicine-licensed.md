# Check if an animal medicine is licensed

Source: https://www.gov.uk/check-animal-medicine-licensed
Fetched: 2026-11-04
Publisher updated: 2014-11-19T12:47:10+00:00

Check the veterinary product information database to find out if a medicine is safe to use on your pet or has been removed from sale.

Find out if a veterinary medicine is currently licensed for use (‘authorised’) to treat pets and other animals.

 Veterinary medicines are licensed to make sure they are safe and effective for specific animals.

 You can also check if a medicine has been removed from sale.
