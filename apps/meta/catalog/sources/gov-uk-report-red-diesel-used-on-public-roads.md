# Report red diesel used on public roads

Source: https://www.gov.uk/report-red-diesel-used-on-public-roads
Fetched: 2026-11-04
Publisher updated: 2014-12-24T13:58:24+00:00

Report someone to HMRC if you think they're using red diesel when driving on public roads without a licence

Report someone to HM Revenue & Customs (HMRC) if they’re using red diesel on public roads.

 It’s illegal to use red diesel on public roads. You can report it to the HMRC Fraud Hotline .
