# Find an MOT tester or manager course

Source: https://www.gov.uk/find-mot-course
Fetched: 2026-11-04
Publisher updated: 2020-02-07T13:28:41+00:00

Find a course so you can qualify as either an MOT tester or an MOT manager

Find your nearest course to become an MOT tester or MOT manager.

You must take an approved:

 MOT tester qualification course before you become an MOT tester 

 MOT manager qualification course before you become an MOT business manager (sometimes called an ‘authorised examiner designated manager’)

 You have to pay to take the course. The prices vary and are set by each course provider.
