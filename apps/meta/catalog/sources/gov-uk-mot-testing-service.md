# Record MOT test results

Source: https://www.gov.uk/mot-testing-service
Fetched: 2026-11-04
Publisher updated: 2017-12-05T17:37:31+00:00

Use the MOT testing service to record MOT test results, update your examiner details, and check and buy MOT slots.

Use this service if you’re an MOT tester and you need to:

 record results of MOTs you carry out

 print MOT certificates

 buy test slots and check your test station’s balance

You need to set up an account before you can use this service.

 If you have an account, you need your:

 user ID

 password

 Help using the service
