# File your Stamp Duty Land Tax return

Source: https://www.gov.uk/sdlt-online
Fetched: 2026-11-04
Publisher updated: 2014-12-24T14:01:34+00:00

Use HMRC's Stamp Taxes Online service to file your Stamp Duty Land Tax (SDLT) return if you're a solicitor, agent or legal conveyancer.

Use the HM Revenue and Customs ( HMRC ) Stamp Taxes Online service to file your Stamp Duty Land Tax ( SDLT ) return if you’re:

 a solicitor

 an agent

 a legal conveyancer

 If you’re an individual buying property and you’re not represented by a solicitor, agent or legal conveyancer, complete a paper return instead.

 Before you start

 Before you can use this service, you must:

 get an agent services account 

 register for the Stamp Taxes Online service 

 File your Stamp Duty Land Tax return

 If you’re filing a return for an additional residential property, choose code 04 when you pick a property type.
